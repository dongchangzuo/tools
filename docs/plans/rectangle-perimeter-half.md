# 半周长页 — 实现计划

> **Route:** `/tools/rectangle-perimeter-half`  
> **UX:** 留白 · 一问一停（同公式页 v2）

## 教学路径

| Phase | 画面 | 字幕 |
|-------|------|------|
| 0 | 长方形 + a、b | （开始） |
| 1 | + 周长 = 16 厘米 | 周长是 16 厘米。 |
| 2 | 红 path 描边 | 红色的长度是多少厘米？ |
| 3 | 表格：红 = a + b | （无） |
| 4 | 绿 path 描边 | 绿色的长度是多少厘米？ |
| 5 | 表格：红 + 绿 = a + b | （无） |
| 6 | 四边 pulse | 红色和绿色，一共是几厘米？ |
| 7 | 揭晓 | 16 ÷ 2 = 8（厘米） / a + b = 8 厘米 |

## 互链

- 首页 → 半周长
- 揭晓后 → 周长探索（P=16）
